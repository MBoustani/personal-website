About

I work at NASA's Jet Propulsion Laboratory in Pasadena, where I apply machine learning and LLMs to real, messy data. I started in geospatial data science, building open-source tools for maps and very large location datasets.

Today I focus on agentic AI: making LLM agents reliable enough to trust with real actions, by putting the rules in code instead of in prompts.
